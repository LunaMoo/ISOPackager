# ISOPackager

Compress, extract, repack and benchmark PSP disc images (ISO, CSO, ZSO, CSO v2, DAX, CHD, EBOOT.PBP),
with an ImGui interface and a command line tool. Built on
[mCSO/maxcso](https://github.com/LunaMoo/maxcso), [CHDmodern](https://github.com/LunaMoo/CHDmodern) and
[iPBP](https://github.com/LunaMoo/iPBP), linked statically from the submodules in `external/`.

**Work in progress** — the engine, CLI and GUI are being written.

```
git clone --recursive https://github.com/LunaMoo/ISOPackager
```
